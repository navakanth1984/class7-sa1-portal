Chapter 1: Formulae and Functions in Excel 2016 (Pages 1–15)

Core Theoretical Concepts:

  1. What is a Formula?
  2. A formula is an expression that calculates values in a cell or range of cells.
  3. Golden Rule: Every formula in Excel MUST begin with an equal sign (=). Without =, Excel treats the entry as plain text.

  4. Elements of a Formula:

    • Mathematical Operators: + (Addition), - (Subtraction), * (Multiplication), / (Division), ^ (Exponentiation), % (Percentage).
    • Cell References (Addresses): e.g., A1, B5, C10.
    • Constants: Numbers or fixed text values directly entered (e.g., =A1 * 10).
    • Functions: Pre-built formula commands (e.g., SUM, AVERAGE).

  5. Cell Ranges:

  6. A cell range is a group or block of contiguous cells selected in a worksheet.
  7. Range notation uses a colon (:) between the top-left cell and bottom-right cell.

  8. Types of Cell Ranges:

    • Vertical Range: Cells located in the same column (e.g., A1:A10).
    • Horizontal Range: Cells located in the same row (e.g., A1:G1).
    • Rectangular Range: A 2D block across multiple rows and columns (e.g., B2:D8).

  9. Cell Referencing Modes:

  10. Relative Referencing: Default mode. Cell references adjust automatically when copied to other cells (e.g., =A1+B1 copied down becomes =A2+B2).
  11. Absolute Referencing: Cell references stay locked to an exact location when copied. Identified by dollar signs ($) before both column and row (e.g., =$A$1).

  12. Mixed Referencing: Either the column is locked or the row is locked (e.g., =$A1 locks column A; =A$1 locks row 1).

  13. Functions & Basic Syntax:

  14. Syntax: =Function_Name(Argument1, Argument2, ...)
  15. Common Functions:
    • =SUM(A1:A5): Adds all numbers in the specified range.
    • =AVERAGE(A1:A5): Calculates the arithmetic mean.
    • =COUNT(A1:A10): Counts cells containing numbers.
    • =MAX(A1:A10): Finds the highest numerical value in the range.
    • =MIN(A1:A10): Finds the lowest numerical value in the range.
    • =PRODUCT(A1:A3): Multiplies all numbers in the specified range.
    • =TODAY(): Returns the current system date.

  16. AutoSum Feature: Located on both the Home Tab (Editing Group) and Formulas Tab. Automatically detects adjacent cell ranges and inserts =SUM(). Shortcut: Alt + =.

  17. Common Excel Error Codes:

  18. #####: Column width is too narrow to display the number, or negative date/time. (Fix: Increase column width).
  19. #DIV/0!: Formula attempts to divide a number by zero or an empty cell.
  20. #VALUE!: Formula contains incorrect argument data type (e.g., adding text to a number: =A1 + "Apple").
  21. #NAME?: Function name is misspelled (e.g., =SUMM(A1:A5) instead of =SUM).
  22. #REF!: Invalid cell reference (occurs when referenced cells were deleted).

D. Answer the following questions in brief:

Q1: Define a Cell Range with an example.

Answer: A cell range is a collection or block of two or more adjacent cells selected in an Excel worksheet. It is represented by the starting cell address and ending cell address separated by a colon (:).

Q2: What is the basic syntax of an Excel function?

E. Answer the following questions in detail:

Q1: Explain the three types of cell referencing in Excel 2016 with suitable examples.

Answer:
1. Relative Referencing: The cell address in the formula changes automatically when copied to another cell based on relative position.
Example: If cell C1 contains =A1+B1 and is copied down to C2, it automatically becomes =A2+B2.
2. Absolute Referencing: The cell address remains locked and does not change when copied. It uses dollar signs before both column and row ($A$1).
Example: In =B2 * $C$1, when copied to row 3, it becomes =B3 * $C$1. Cell C1 remains constant.
3. Mixed Referencing: Either the column is locked or the row is locked, but not both.
Example: =$A1 (locks column A, row changes) or =A$1 (locks row 1, column changes).

Chapter 2: Charts in Excel 2016 (Pages 16–29)

Core Theoretical Concepts:

  1. What is a Chart?
  2. A chart is a graphical, pictorial representation of numeric worksheet data.

  3. Benefits: Visualizes trends, simplifies complex data, enables instant comparison, and makes presentations impactful.

  4. Components of a Chart:

  5. Chart Area: The entire chart window including all objects, titles, legends, and plot area.
  6. Plot Area: The bounded rectangular area where the actual data is plotted, surrounded by axes.
  7. Chart Title: Descriptive heading placed at the top explaining what the chart represents.
  8. Category Axis (X-Axis): The horizontal axis displaying data categories (e.g., Student Names, Months).
  9. Value Axis (Y-Axis): The vertical axis displaying numerical values/measurements (e.g., Marks, Sales).
  10. Data Series: The actual visual bars, slices, columns, or lines that represent individual data points.
  11. Legend: A color-coded or patterned key identifying which color/symbol corresponds to which data series.
  12. Gridlines: Horizontal and vertical lines extending across the plot area to make reading values easier.

  13. Data Labels: Labels that show the exact numerical values directly on top of the bars or data markers.

  14. Types of Charts in Excel 2016:

  15. Column Chart: Uses vertical rectangular columns to compare items across categories over time.
  16. Bar Chart: Uses horizontal bars; ideal when category names are long or comparisons are non-temporal.
  17. Line Chart: Displays continuous data points connected by straight lines; best for showing trends over time (e.g., stock prices, temperature).
  18. Pie Chart: A circular disk divided into proportional slices; shows the relationship of parts to a whole for a single data series (percentages).
  19. Area Chart: Highlights the magnitude of change over time by shading the area below the line.

  20. Scatter (XY) Chart: Plots pairs of numerical values to show correlations or scientific relationships.

  21. Modifying and Customising Charts:

  22. Chart Tools Contextual Tabs: When a chart is clicked, two tabs appear on the Ribbon: Design and Format.
  23. Chart Elements Button (+): Quick shortcut floating beside the chart to add/remove Data Labels, Axis Titles, and Legends.
  24. Moving a Chart: Click Move Chart in the Location group on the Design tab to move the chart to a dedicated Chart Sheet or another worksheet.

Chapter 3: Advanced Features of Excel 2016 (Pages 30–41)

Core Theoretical Concepts:

  1. Sorting Data:
  2. Organizing data in a specific sequential order to analyze it efficiently.
  3. Sort Orders:
    • Ascending Order: Smallest to largest (Numbers) or A to Z (Text).
    • Descending Order: Largest to smallest (Numbers) or Z to A (Text).

  4. Custom / Multi-Level Sorting: Sorting data by more than one column (e.g., first sort by Department in alphabetical order, and within each department, sort by Salary from largest to smallest). Located on Data Tab $\rightarrow$ Sort.

  5. Filtering Data:

  6. Filtering extracts and displays only the records that meet specified criteria, temporarily hiding unwanted rows.
  7. Unlike sorting, filtering does not rearrange data; it selectively hides non-matching rows.
  8. AutoFilter: Added by selecting headers and clicking Data Tab $\rightarrow$ Filter (Shortcut: Ctrl + Shift + L). Small dropdown arrows appear on each column header.

  9. Filter Types:

    • Number Filters: Equals, Does Not Equal, Greater Than, Less Than, Between, Top 10.
    • Text Filters: Equals, Contains, Begins With, Ends With.

  10. Conditional Formatting:

  11. Allows users to automatically apply specific formatting (fill colors, font bolding, borders, data bars, icon sets) to cells that fulfill certain criteria.
  12. Located on: Home Tab $\rightarrow$ Styles Group $\rightarrow$ Conditional Formatting.
  13. Presets include:
    • Highlight Cells Rules (Greater Than, Less Than, Between, Equal To, Text that Contains).
    • Top/Bottom Rules (Top 10 Items, Top 10%, Below Average).
    • Data Bars, Color Scales, and Icon Sets.

Chapter 4: Introduction to Adobe Animate 2020 (Pages 42–55)

Core Theoretical Concepts:

  1. What is Adobe Animate 2020?

  2. Adobe Animate is a professional multimedia vector animation authoring software used to create interactive 2D vector animations, banner advertisements, cartoons, animated web graphics, and interactive educational content.

  3. Workspace Components of Adobe Animate:

  4. Menu Bar: Top of the screen providing access to commands (File, Edit, View, Insert, Modify, Text, Commands, Control, Window, Help).
  5. Stage: The central white rectangular canvas where graphics, drawings, animations, and text are placed. Only elements placed within the stage boundaries appear in the exported movie.
  6. Pasteboard: The gray background area surrounding the stage. Used to store objects, work on elements off-screen, or position items that will animate into the stage later.
  7. Timeline: The vital panel (usually at the bottom) that organizes and controls the animation's timing, frame rate, layers, and sequencing.
  8. Layers: Transparent sheets stacked on top of one another, allowing different animated objects to be drawn and manipulated independently without interfering with each other.
  9. Frames & Keyframes:
    • Frame: Individual unit of time represented by small rectangular boxes along the timeline.
    • Keyframe: A critical frame (marked with a black solid dot) where a new symbol appears, changes position, or initiates an action. Shortcut: F6.
    • Blank Keyframe: A keyframe with no content on the stage (marked with an empty circle). Shortcut: F7.
  10. Tools Panel: Contains all creative drawing, painting, selection, and transformation tools (Selection, Free Transform, Rectangle, Oval, Brush, Eraser, Eyedropper).
  11. Properties Panel: Contextual inspector displaying properties (size, color, stroke weight, font, coordinates) of whatever tool or object is currently selected.

  12. Library Panel: Central storage locker containing reusable graphic symbols, buttons, movie clips, sound effects, and imported bitmaps. Shortcut: Ctrl + L.

  13. Strokes and Fills:

  14. Stroke: The outer border or outline of a shape. Attributes include Stroke Color, Stroke Width, and Stroke Style.
  15. Fill: The interior body color, gradient, or pattern inside a closed shape.

  16. Eyedropper Tool (I): Used to sample and pick colors or stroke styles directly from existing stage objects.

  17. Symbols & Animation:

  18. A Symbol is an original graphic, button, or movie clip stored once in the Library and reused multiple times as Instances on the Stage.
  19. Converting an object to a Symbol: Select object $\rightarrow$ Press F8 (or Modify $\rightarrow$ Convert to Symbol) $\rightarrow$ Name symbol and choose type (Movie Clip, Button, or Graphic).
  20. Text Animation:
    • Type text with the Text Tool (T).
    • Break text apart into individual letters using Ctrl + B.
    • Convert each letter into a graphic symbol (F8).
    • Distribute to layers and apply Create Classic Tween or Create Motion Tween between keyframes.

6. Move or rotate the letters to their final positions on Frame 30.
7. Right-click between Frame 1 and Frame 30 and choose Create Classic Tween to produce smooth motion.
